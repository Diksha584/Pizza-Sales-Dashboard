# 🍕 Pizza Sales Dashboard – Power BI

## 📌 Overview
This project presents an **interactive Power BI dashboard** designed to analyze **Pizza Sales data** and generate actionable business insights.  
The dashboard highlights sales trends, customer behavior, and product performance through intuitive visualizations.

## 🎯 Objective
- Analyze overall sales and revenue performance  
- Identify busiest days and peak sales periods  
- Understand sales distribution by pizza category and size  
- Identify best-selling and worst-selling pizzas  
- Support data-driven business decisions  

## 🧹 Data Cleaning
- Removed duplicate and null records  
- Standardized column names and data formats  
- Corrected data types for dates, prices, and quantities  
- Ensured consistency across pizza categories and sizes  

## 📚 Data Learning
- Understood customer ordering patterns across days and months  
- Analyzed revenue contribution by pizza category and size  
- Identified high-demand and low-demand pizza items  
- Observed peak order times and seasonal trends  

## 📊 Dashboard Structure
The Power BI report includes **two main tabs**:

### 1️⃣ Home Dashboard
- Total Revenue, Total Orders, and Total Pizzas Sold  
- Average Order Value & Average Pizzas per Order  
- Daily and Monthly order trends  
- Sales breakdown by Pizza Category and Pizza Size  

### 2️⃣ Best / Worst Sellers
- Top 5 and Bottom 5 Pizzas based on:
  - Revenue  
  - Quantity Sold  
  - Total Orders  

## 🛠 Tools & Technologies
- Power BI  
- DAX  
- Data Modeling  
- Data Cleaning & Transformation  

## 📈 Key Insights
- Classic category contributes the highest sales and total orders  
- Large-size pizzas generate maximum revenue  
- Weekend evenings record the highest number of orders
